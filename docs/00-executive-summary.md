# executive-summary

Lamyig exists because the best travel knowledge in remote India — where the homestays are, where the mechanic is, where the water is clean, where the network dies — lives in tea-stall conversations and WhatsApp groups, not on any map or booking site. See [`01-founder-story.md`](01-founder-story.md) for how that gap became visible on the road.

Lamyig is an open, community-maintained travel knowledge platform. It preserves and organises local travel knowledge so remote communities become discoverable, and so independent travellers can explore with confidence — without becoming a booking platform, a navigation app, or another review site.

The platform is built around information, not transactions. Every feature is tested against one question: does this help a traveller discover reliable information? If not, it doesn't belong in the MVP. See [`06-product-philosophy.md`](06-product-philosophy.md).

**The biggest product decision:** Lamyig is not a map. It is a community-maintained travel knowledge base, organised geographically (India → State → Region → Village → Place). The map is one interface for exploring that knowledge, not the product itself. See [`07-information-architecture.md`](07-information-architecture.md).

**Scope:** India-wide from launch, not limited to any single region. Spiti, Ladakh, Zanskar, Sikkim, and major treks are the featured, founder-seeded starting regions — not the boundary of the product. See D-009 in [`14-decision-log.md`](14-decision-log.md).
