# problem

The problem is not accommodation. The problem is not navigation. The problem is fragmented travel knowledge.

The information a traveller in remote India actually needs — reliable homestays, working mechanics, clean toilets, drinking water, mobile network coverage by operator, campsites, road conditions — already exists. It's just scattered across Google Maps, YouTube, Instagram, blogs, WhatsApp groups, Facebook groups, tea-stall conversations, and the memory of the last rider who passed through.

No single community-maintained platform organises this into a searchable, structured format.

Remote regions are not lacking services. They are lacking discoverability. Lamyig exists to solve the discoverability problem — not to add another service on top of the ones that already exist.

See [`01-founder-story.md`](01-founder-story.md) for the specific incidents (Shego, Losar, Gue, Shichling, Kargyak, the puncture near Reckong Peo) that surfaced this pattern.
